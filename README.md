# Rotaray

A personal companion web app (PWA) for a European train-route board game. Each player uses it on their own phone:
tap routes to mark who claimed them, track trains, stations and score, rotate the map for the other side of the table,
and keep a history of finished games. English and Turkish. Works offline.

> Unofficial fan-made companion app, not affiliated with Days of Wonder. The map is drawn from real geography in an
> original style; it contains no board artwork.

See [IMPLEMENTATION_PLAN.md](IMPLEMENTATION_PLAN.md) for the design and roadmap (ticket chooser, strategy builder and
real-time multiplayer come later).

## Develop

```bash
npm install
npm run dev        # http://localhost:5173
npm test           # unit tests (Vitest)
npm run lint
npm run build      # type-check + production build (PWA)
npx playwright install chromium   # once
npm run e2e        # end-to-end tests on a phone viewport
```

## How it works

- **Event-sourced state.** The app stores a list of actions (`src/game/actions.ts`) and computes the game with a pure
  reducer (`src/game/reducer.ts`). Undo removes the last action; saving persists the list to IndexedDB. `src/game`
  has no React or browser code so a future multiplayer server can run the same reducer.
- **Map data** lives in `src/data/json` (cities, routes, tickets) and is checked by `tests/data.test.ts`.
  Please verify it against your physical board.
- **Sync adapter** (`src/sync`) hides where the action log is stored. v1 uses `LocalAdapter` (IndexedDB).
- City label positions are precomputed (`src/ui/map/labelLayout.json`). After changing the map layout, regenerate
  them with `UPDATE_LABELS=1 npm test`.
- Icons are generated by `node scripts/make-icons.mjs`.

## Deploy

The output of `npm run build` is a static site in `dist/`. Host it on any static host with HTTPS (Cloudflare Pages,
Netlify, GitHub Pages) — HTTPS is required for installing the PWA and for the service worker.
